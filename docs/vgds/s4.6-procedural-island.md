# S4.6：Procedural Island Terrain

2026-10-29。新增 IslandTerrain.hpp/.cpp，扩展 OsgBuilder.cpp/OsgMesh.hpp、配置、Source-loaded 回调和客户端内存建模路径，新增 IslandTerrainTests.cpp。

保留原始完整来源对象，以 sourceObjectId+dataVersion 定位海岸；只用 Geographic 边建立岸线段 BVH。Unknown、人工 Tile 边和 Catalog 所有权裁剪边不参与距岸计算。孔洞的真实岸线也参与。高度和法线查询均在全局投影坐标进行，不用每块自己的轮廓归一化。

当前模拟公式：

```text
d = 到该完整来源对象真实岸线段的最短距离
z = H * clamp(d / R, 0, 1)^p
normal = normalize(-中央差分 dz/dx, -中央差分 dz/dy, 1)
```

默认 H=42 m、R=200 m、p=1.25、差分步长 0.5 m。R 是配置的统一米制岸距尺度，替代旧 IslandBuilder 在离散网格上重算的 dMax，避免 Tile 或采样密度改变整岛高度尺度。H 是上限，小岛可能达不到 H；到达 R 后可形成平顶峰。它恢复距岸生成起伏的原则，不声称逐顶点复刻旧示例。没有已确认海岸的来源对象保持 0 m，不从 Unknown 边猜测岸线。

渲染以配置 GridSpec 为锚，在全局 25 m 网格中裁剪各个陆地片段；每个小面保留孔洞/MultiPolygon，再 Earcut 剖分并加入三角形重心采样。公共网格线及轮廓交点形成相同接缝分段，避免两侧独立细分造成 T 型接缝。顶点 Z/法线/颜色来自同一来源函数。只有 Geographic 边连接到底部 -12 m，人工边无侧壁。XYZ 比例仍为 1:1。

原始二维 Feature 与 TilePackage 几何不变。完整来源上下文位于本地 IslandTerrain 对象，通过 Source-loaded 回调注册；OSGB 为生成结果。关闭 OSGB 时，makeLoader 使用相同上下文在内存建模；不能仅用孤立裁片恢复完整高度场。上下文独立限量，默认最多 16 个来源单元，避免航行历史无限保留。跨进程无 OSGB 客户端尚未定义这个上下文的传输协议。

旧平顶 buildOsgb 兼容入口继续存在，旧配置未启用 island_terrain 时仍使用 12 m 平顶。新默认 Catalog 配置启用程序化山形，参数变化会改变 Builder 版本和缓存键。

S4.6 实测 305 项检查通过：原始岸线为 0 m、内部有起伏、参数和版本隔离、Unknown 不制造山形、OSGB 反读、接缝分段匹配、公共顶点高度/逐顶点法线误差小于 1e-6、无人工侧壁。截图 output/vgds/s7-land.png 展示真实 LNDARE 轮廓上的模拟起伏。

最短岸距函数在山脊可不可微；统一差分保证两块使用相同法线，不保证山脊处数学 C1 光滑。不同海图中的来源对象不自动视为同一完整岛屿；跨来源高度融合仍是限制。数据始终是 Synthetic 模拟陆地，不是 ENC 测量高程。
