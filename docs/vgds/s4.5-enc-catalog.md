# S4.5：ENC Catalog

2026-10-29。新增 Catalog.hpp/Catalog.cpp、TileCache.hpp/.cpp；扩展 Geometry.cpp 的任意多边形掩码求交，配置与 CLI 接入 CatalogProvider。没有新增构建目标或下载依赖。

Catalog 递归发现 .000，跟踪同名单元更新文件的 SHA-256，读取应用更新后的 DSID、比例尺和 M_COVR。CATCOV=1 是覆盖区，CATCOV=2 从覆盖区扣除；投影到配置的米制 CRS。持久索引保存版本、比例尺、edition/update、投影覆盖 WKT 和来源路径；启动重新计算文件摘要，未变化的条目复用，不重读覆盖几何。

query(Tile bounds) 先查包围盒，再查实际覆盖。owner(XY) 按最小 compilationScale 分母优先，同级按 cell 名稳定排序。ownedRegion 依次扣除更高优先级海图的覆盖，在同一 Tile 中用多个互不重叠的面片补齐数据，不直接叠加完整海图。重叠区域不按几何中心散列选图。覆盖边新增边标 ArtificialClip，不能成为真实海岸。点同时遵守优先来源和半开 Tile 归属。

覆盖查询和海底掩码使用现有 GDAL/GEOS Prepared Geometry 加速，类型只在 src/vgds/PreparedShape.hpp 内部出现。公共头保持 STL。外部公开 EncCatalog、CatalogProvider、CatalogConfig、CatalogStats。

按需解析图幅，常驻 Dataset 默认最多 3 份，LRU 淘汰。TilePackage 缓存键含规范化请求、相关图幅内容版本、完整网格、数据层开关、生成算法与 Builder 参数版本。命中渲染缓存时不必解析原始 ENC。缓存默认 128 项/512 MiB；来源图幅缓存与区块磁盘缓存是两种独立资源。

本项目实测发现 48 个 ENC 基础文件，总计约 15 MB。S4.5 测试验证全部发现、冷建索引、重启复用、实际区块返回、重复请求不重解析、无覆盖 NoCoverage、优先区域面积不重叠及缓存上限。S7 又验证了 Rhode Island 详细海图自动选择与源 LRU 淘汰。记录见 output/vgds/catalog-validation.json、s7-validation.json。

入口：config/vgds-catalog.json；索引：output/vgds/enc-catalog.json。没有 HTTP，主程序通过同进程 JSON 请求入口调用，独立 VgdsService 使用相同 JSONL 契约。新增/更新 ENC 文件后重新启动以刷新索引，不实现目录实时监控。坏的索引可重建，坏的源图幅以错误报告，不默默当无覆盖。跨图幅原始轮廓、精度和垂直基准可能不同；这里定义选择规则，不声称完成跨比例尺地理融合。
