# 海底地形实验区域 001：实现与验收

## 输入和范围

- 源文件：`S57_DATA/ENC_ROOT/US2EC04M/US2EC04M.000`，同目录 `.001` 自动应用。
- 西南角：`(-68.956311, 43.861511)`；东北角：`(-68.944175, 43.870504)`。
- 最终投影面积：974,019.194 m²，约 0.974 km²。
- 输出投影：EPSG:32619，默认 5 m 网格，196 列 × 200 行。
- 水深来源：`DEPCNT.VALDCO` 与 `SOUNDG` 几何 Z；区域和深度范围来自 `DEPARE`。
- 不读取陆地层，不生成陆地地形，不做潮位或垂直基准转换。

原海图的编绘比例尺为 1:675,000。5 m 是输出网格间距，不代表原始资料具有 5 m 测量分辨率或相应高程精度。

## 区域数据与重建判断

ROI 中有 3 条等深线要素，深度为 5.4、18.2、36.5 m；有 4 个 DEPARE 区间：

| 水深范围（m） | ROI 内投影面积（m²，约） |
| --- | ---: |
| 0–5.4 | 394,385 |
| 5.4–18.2 | 278,786 |
| 18.2–36.5 | 224,033 |
| 36.5–91.4 | 76,815 |

ROI 中只有一个测深点：`(-68.9478428, 43.8698181)`，水深 1.8 m。不能仅依靠这个点恢复浅水区的真实细节。

默认读取周边 20 km 支撑范围，实际获得 23 个 DEPARE、22 个 DEPCNT 要素（1,159 条线段）和 42 个有效测深点。91.4 m 支撑线在 ROI 外，使用边界外数据可使深水区间形成坡面。浅水区缺少 0 m 等深线，所以采用 5.4 m 单侧基面与该测深点的局部残差修正；远离测深点的位置仍可能平坦。这是数据不足的显式保守结果。

此外，西北角存在 73.178 m 的不兼容 DEPARE 公共边界。严格满足两侧范围时，相邻像元最大高程跳变为 18.664 m。最终成果对该边界做 100 m 局部过渡，同时保留原始约束版本，细节见 [技术文档第 6 节](technical-design.md)。

## 输出文件

| 文件（位于 `output/region001`） | 内容 |
| --- | --- |
| `region001_elevation.tif` | 最终连续海底高程，Float32，负值代表基准面以下 |
| `region001_elevation_raw.tif` | 过渡修复前的高程，逐像元满足所属 DEPARE 区间 |
| `region001_quality.tif` | 同网格的质量分类：0 无效、1 双侧等深线、2 单侧、3 源数据冲突过渡 |
| `region001_sources.gpkg` | ROI、三个源图层的 `_roi` 与 `_support` 提取，以及 `DEPARE_conflicts` 冲突线 |
| `region001_report.json` | 参数、来源计数、面积、覆盖、冲突处理、高程范围与垂直基准代码 |
| `region001_sounding_check.csv` | 支撑测深点的观测值和算法原位置求值，用于复现检查 |
| `region001_terrain.osgt` | OSG 网格及 UTM 局部原点/CRS 元数据 |
| `region001_preview.png` | 高程、等深线、测深点和质量分区图 |

## 本次验收结果

| 指标 | 结果 |
| --- | ---: |
| ROI 内有效像元 | 39,000 / 39,000 |
| ROI 外像元 | 200，均为 NoData |
| ROI 内无支撑空洞 | 0 |
| 修复前单侧基面像元 | 15,773（约 40.44%） |
| 局部冲突过渡像元 | 940（约 2.41%） |
| 最终高程范围 | -36.854630 至 -1.800315 m |
| 最终最大相邻像元高程差 | 2.15189 m / 5 m 网格 |
| OSG 顶点数 | 39,200，其中 NoData 顶点不参与三角形 |
| OSG 三角形数 | 77,212 |
| CTest | 4 / 4 通过 |

质量 3 覆盖原有 1/2 分类，所以“修复前单侧像元”与“过渡像元”不能直接相加。局部过渡结果放宽了数值区间，但没有扩大 ROI 或填入区域外像元。没有独立测深集，因此不能把这些工程校验当作真实高程精度评估。
